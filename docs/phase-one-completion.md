# Завершение фазы 1

Статус на 2 октября 2026. Реализация и локальная проверка отделены от работы внешних сервисов.

## Реализовано и проверено локально

- [x] Календарь мастера на день/неделю, ночные заказы в двух днях, доступ только к своей студии.
- [x] Загрузка по сохранённым рабочим интервалам, пересечения и перерывы, отсутствие вымышленных свободных смен. Обработка пропущенного часа при переходе на летнее время.
- [x] Пошаговое подключение студии: контакты, услуги, команда/график, готовность.
- [x] Поддержка: поиск студий, изменение подписки с причиной и аудитом, проверка роли на сервере.
- [x] Очередь email, журнал, повторы явных отказов и ручная проверка неизвестного результата доставки.
- [x] Повторные визиты только при согласии клиента и настройке интервала; повторный запуск не создаёт дубли, новая запись отменяет потребность в напоминании.
- [x] Push: подписки устройств, события назначения/проверки/подтверждения, проверка блокировки, удаление недействительных подписок.
- [x] Восстановление незавершённой привязки администратора после подтверждения почты; повторное приглашение не обходит блокировку.
- [x] Мобильный цикл на синтетических данных: назначение → смена → чек-лист → проверка → 300 ₴ начислено → 100 ₴ выплачено → 200 ₴ остаток.
- [x] Мобильный чек: 1 500 ₴ − скидка 100 ₴ = 1 400 ₴. Проверены экраны 360/390 px и 1440 px, формы календаря и подписки.
- [x] Расширены UA/RU/EN: формы, статусы, сообщения, числа и даты. Названия услуг и имена в выпадающих списках сохраняют пользовательский текст.
- [x] Расчёты финансов, календарь, сроки заказов/обращений и основные временные метки используют часовой пояс студии.
- [x] SQL 040–044 проверен при первом и повторном запуске. Пользователь подтвердил успешное применение в основном Supabase 2 октября.
