# Выпуск платформенных функций — 30 сентября 2026

## Реализовано

- Биллинг: оплата месяца через WayForPay, проверка подписи/суммы/валюты, повторный callback без двойного продления, ограничения срока и количества мастеров.
- Администраторы студии: приглашение, блокировка, восстановление пароля и отдельный доступ к финансам. Ограничения проверяются API и правилами БД.
- Специализации: все услуги либо выбранные; проверка при онлайн/ручной записи и назначении работ.
- CRM: редактируемые контакты, заметки, теги, несколько автомобилей и история посещений.
- Чеки: неизменяемый состав и цены, скидка, печать/PDF, фильтры и журнал оплат. Это информационные документы, без фискализации.
- Ручная запись: создание клиента, автомобиля, записи и услуг в общей транзакции; варианты, часовой пояс, повторный запрос без дубля.
- PWA: установка, экран без сети и управляемое обновление версии. Приватные ответы API не кэшируются.
- Языки: переключатель UA/RU/EN и словарь основных экранов/полей. Часть пояснений, динамических уведомлений и серверных ошибок ещё остаётся на украинском; полный перевод не завершён.
- Эксплуатация: CI, endpoint /api/health, журнал изменений только для владельца, инструкция резервирования и восстановления.
