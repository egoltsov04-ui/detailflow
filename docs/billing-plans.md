# Тарифы и права

Тарифы отличаются числом активных профилей мастеров: Start — 690 грн/месяц, 3; Studio — 1490 грн/месяц, 10; Pro — 2990 грн/месяц, без лимита. Во всех тарифах доступны календарь, онлайн-запись, CRM/импорт, работы и проверка, кабинет мастера, смены, зарплата, склад, финансовые отчёты и чеки. Доставка уведомлений зависит от настройки каналов; действующий этап рабочего email-отправителя приостановлен пользователем.

Активное приглашение занимает место мастера. Заблокированный/неактивный профиль места не занимает; повторная активация проверяет лимит. Учётная запись владельца или администратора сама по себе не занимает место, но отдельный активный профиль мастера для этого же человека учитывается.

Понижение тарифа не скрывает и не удаляет мастеров: при превышении нового лимита смена отклоняется. Сначала нужно деактивировать лишние профили. Завершение срока доступа не удаляет старые данные и не останавливает работу с текущими заданиями, но запрещает новые заказы и активацию мастеров.

Тариф доступен только активным владельцу и администратору своей студии. Администратору не требуется finance_access для просмотра подписки и продления; это не даёт доступа к зарплатам/кассе. Мастер не видит тариф в интерфейсе и не может получить подписку/платежи через RLS или get_studio_billing. Провайдерские payload и финансовые учётные данные не выдаются.

Продление сейчас согласуется с @detailflow. Владелец и администратор обращаются из раздела «Тариф і продовження»; поддержка подтверждает срок в /admin с обязательной причиной и записью в журнал. Пользователь не может сам поставить статус «оплачено». WayForPay остаётся выключенным по умолчанию, но его серверная проверка допускает активного владельца или администратора этой студии и проверяет вместимость выбранного тарифа.

Изменения базы: 046_billing_roles_limits.sql, повторный запуск проверен. Проверки: 54 теста, клиентские и серверные типы, production-сборка. Миграция применена в основной базе 3 октября 2026 года; SQL Editor подтвердил успешное выполнение.
