# Правила продукта Detailflow

## Навигация

Восемь разделов, порядок фиксирован: Огляд, Роботи, Клієнти, Фінанси, Склад, Команда, Аналітика, Налаштування. Новые разделы без запроса не добавлять. Аналітику (графики и расчёты) не менять без прямой просьбы.

## Одна сущность, одно место

- Заказ открывается в одной общей панели (OrderPanel) из любого экрана: календарь, канбан, список, клиент. Действия над заказом (статус, оплата, майстер, фото, чек) только там. На других экранах только показ и вход в панель.
- Календарь, канбан и список должны различаться по смыслу: календарь отвечает «когда и на каком посту», канбан «на каком этапе», список «найти и отфильтровать». Не делай три копии одного и того же.
- Не дублируй одно и то же действие в нескольких местах. Если элемент повторяется, оставь один.
- Схема постов студии 2D, без 3D.

## Роли

- Владелец: всё.
- Адміністратор: операции студии, финансы и зарплаты только с флагом «Доступ до фінансів та зарплат».
- Майстер: только свои работы, свой график и свои начисления. Не видит финансы студии и чужие заказы.
- Support (`/admin`): панель сотрудников платформы. Видит студии, подписки и тикеты, не видит бизнес-данные без необходимости. Реальное разделение прав делает база, не интерфейс.

## Тарифы (гипотеза, не хардкодить)

Solo 390, Студія 1190, Pro 2490 грн в месяц. Ограничения тарифов хранятся в конфиге флагов функций, а не размазаны по коду. В Solo владелец является майстром (без отдельных ролей и лишних экранов). Оплата сейчас ручная через Telegram (режим `manual`). Цены и состав тарифов без запроса не менять.

## UI

- Тёмная тема. Фон #171A22, акцент #A7D65C, карточки #22262F, границы #2C303C, текст #FFFFFF и #C7CAD1, приглушённый #6D7280.
- Шрифты: Montserrat ExtraBold для заголовков, Manrope для текста, Inter Black для цифр.
- Мобильная версия обязательна: 375, 768 и 1440 px, без горизонтального скролла, элементы нажимаются пальцем (минимум 44 px).
- Нет наложения текста и карточек, нет белых плиток на тёмном фоне, нет тавтологий в подписях (не «Клієнти: список клієнтів»).
- Таблицы и графики читаются без пояснений. Графики по тику, как в текущей версии, сохранять.
- Тексты на украинском, через i18n. Любой новый текст добавляется во все языки.

## Известные проблемы (проверь, не исправлены ли уже)

- Сообщение «Підписку не знайдено» у части пользователей.
- Автозакрытие смен и перерывов.
- Склад: шаг изменения количества 0.001.
- Страница тарифов: перекрытие элементов.
- Скидка: нет проверки максимума.
- Карточки клиентов выглядят грубо, нужен аккуратный вид.

## Перед изменением UI

Прочитай существующие компоненты и переиспользуй их. Покажи мне план. После изменений проверь экран на трёх ширинах и пройди сценарий по каждой затронутой роли.
